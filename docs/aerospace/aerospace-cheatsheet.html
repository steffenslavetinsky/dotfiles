AeroSpace Cheat Sheet

i3-style tiling window manager for macOS
modifier key = Alt (⌥)
How it works. Every window is a leaf in a tree that AeroSpace tiles to fill the screen — no overlapping, no manual placement. Splitting direction alternates as you nest. You get 9 numbered workspaces (virtual desktops that don't animate like macOS Spaces). Two extra modes — resize and service — remap the keyboard temporarily so single keys do the work; press esc to return to normal.

Main Focus & launch

⌥+H J K L Move focus left / down / up / rightHighlights the neighbouring window in that direction.
⌥+⏎ Open a terminalLaunches a new ghostty window (open -na ghostty).

Main Move & resize windows

⌥+⇧+H J K L Move window left / down / up / rightSwaps the focused window with its neighbour in the tree.
⌥+- Shrink focused windowSmart resize by 50px along its split axis.
⌥+= Grow focused windowSmart resize by 50px along its split axis.
⌥+⇧+F Fullscreen toggleFocused window fills the monitor; press again to restore tiling.

Main Layout

⌥+/ Toggle tiles horizontal / verticalFlips whether the current container splits side-by-side or stacked.
⌥+, Toggle accordion layoutCollapses siblings into a stack showing one at a time (like tabs).

Main Workspaces

⌥+1…9 Switch to workspace 1–9Jumps to that virtual desktop.
⌥+⇧+1…9 Send window to workspace 1–9Moves the focused window there; focus stays put.
⌥+Tab Back-and-forthToggle between current and previously focused workspace.
⌥+⇧+Tab Workspace to next monitorMoves the whole workspace to the next display (wraps around).

Resize enter with ⌥+R

H / L Narrower / widerAdjusts width by 50px per press.
J / K Taller / shorterAdjusts height by 50px per press.
⏎ / esc Back to main modeLeaves resize mode.

Service enter with ⌥+⇧+;

esc Reload configRe-reads aerospace.toml, then returns to main. Use after editing.
R Reset layout treeFlattens the workspace so windows re-tile evenly.
F Toggle float / tilePops the focused window out of tiling (or back in).
⌫ Close all but currentCloses every other window in the workspace.
⌥+⇧+H J K L Join with neighbourMerges the focused window into the adjacent container in that direction.
